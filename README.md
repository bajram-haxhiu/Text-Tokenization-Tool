# Text Tokenization & Comparison Tool

## Overview
This project compares three text tokenization methods in Python: `split()`, NLTK, and spaCy.

It examines how different tokenizers process contractions, numbers, dates, punctuation, email addresses, and URLs.

## Technologies
- Python
- Jupyter Notebook
- NLTK
- spaCy
- Pandas
- Matplotlib

## Features
- Compare three tokenization methods.
- Calculate token counts and basic text statistics.
- Identify frequently used words.
- Visualize results using bar charts.
- Analyze tokenization differences across various text examples.

## Project Structure
- `tokenization_analysis.ipynb` — Main notebook containing the code and visualizations.
- `requirements.txt` — Required Python libraries.
- `README.md` — Project documentation.

## Installation
Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open `tokenization_analysis.ipynb` and run the cells.
